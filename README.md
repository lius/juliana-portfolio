# Juliana Romero — Arquitetura

Portfólio profissional de Juliana Romero, arquiteta com experiência em
arquitetura hospitalar, compatibilização e gestão de projetos.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

O projeto usa React, TypeScript e Vite e está configurado para publicação no Netlify.
